# 声骸调谐概率：中文说明

> 依据库洛韩文官方公示整理，并非库洛发布的官方中文原文。

原始来源：[库洛官方韩文概率公示](https://sdk-global.kurogames.com/pro/agreement/common/language_ko/product_info)。查阅日期：2026-10-02。下列中文名称与本项目识别、评分名称对应；数值按该官方页面的普通五星声骸调谐表整理。

## 1. 先抽类型，再抽该类型的数值

普通五星调谐共有 **13 种副词条类型**。已经激活的副词条类型不会重复出现，主词条类型不因此从副词条池中排除。

设已激活副词条数为 n（0 ≤ n < 5），则下一个尚未出现的指定类型的概率为 **1 / (13 − n)**。

**下一个指定未出现类型及指定数值的概率 = 1 / (13 − n) × 该类型该数值的条件概率。**

这里的“条件概率”表示：已确定抽到该类型之后，抽到某档数值的概率。下表的百分比需要除以 100，再代入公式；本项目还会按同组公示总和归一化，见第 3 节。

例如，已有 4 条且尚未出现暴击时，下一条为最高档暴击（10.5%）的模型概率为 (1 / 9) × (3 / 99.9999)，约为 **0.3333337%**。这不是任意声骸达到最高评分的通用概率，后者还取决于评分模板、现有词条和所有并列最高分组合。

## 3. 为什么要归一化

官方公示的概率保留有限小数位，各档相加会有微小舍入差异：

- 暴击组：99.9999%
- 普通八档组：99.9998%
- 固定攻击组、固定防御组：分别为 100%

**模型使用的某档条件概率 = 该档公示数值 / 同组所有档位公示数值之和。**

例如暴击最高档使用 3 / 99.9999；普通八档组最高档使用 2.9126 / 99.9998。每组分别归一化，不混用各组分布。原始百分比仍保留在上表和代码中，便于核对。

## 4. 如何得到最终评分概率

设当前评分为 B、剩余槽位数为 k = 5 − n。当前评分沿用项目原有规则：主词条按 +25 满级值计分，加上已识别副词条。每个未来词条仍按模板权重计算，并逐条截断到两位小数；技能伤害词条还乘对应技能权重。50 分是评分尺度，不是强制上限。

- 从剩余 13 − n 种类型中不重复选择 k 种。每个无序类型组合的概率相同，为 1 / C(13 − n, k)。
- 在每个选中类型内，按该类型的数值条件概率计算分数。
- 将所有产生相同最终评分 S 的路径概率相加。零权重词条、截断后的同分档位和并列最优组合都保留。
- **达到目标的概率 = 所有 S ≥ 目标评分的结果概率之和。**
- **达到当前理论最高分的概率 = 所有达到该声骸当前可达上限的结果概率之和。**
- **期望最终评分 = Σ（最终评分 S × 该评分的概率）。**期望是平均数，不保证能实际抽到。

五条副词条全部激活时，已无后续随机性：期望终分等于当前评分，达当前上限的概率为 100%，达目标概率根据当前评分是否达到目标为 100% 或 0%。

## 5. 适用范围与模型假设

- 仅用于普通五星声骸调谐；声骸重构、锁定词条后的重洗及改变候选池的其他机制不适用。
- 不同次调谐的数值档位相互独立，以及韩文公示对其他地区同样适用，均为本项目的模型假设，不能将其表述为中文官方声明。
- OCR 不能可靠证明稀有度、等级或整行词条是否遗漏。概率以“已识别主副词条和 COST 正确，且已激活词条没有遗漏”为条件；请在游戏中核对。
- 计算是确定性的，没有蒙特卡洛抽样误差；公示本身有舍入精度和适用范围限制，因此展示的是估计概率。

可核对实现：[`echo_probability.py`](echo_probability.py) 中的概率分组与计算，及 [`echo_score.py`](echo_score.py) 中的属性档位与原有评分规则。
